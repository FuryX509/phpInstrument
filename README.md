PTracewithinpute is a Frida-based script that hooks into the HTTPD or PHP core to instrument and analyze the execution flow of PHP-based applications at runtime. It tracks which files and functions are triggered during a single user request, based on the executed filename.
During white-box analysis, it is often necessary to identify the exact execution path initiated by a user action. While tools such as CodeQL can be used for this purpose in static analysis, they did not fully meet this requirement in my case. As a result, this script was developed to dynamically extract and observe the real execution flow during runtime.
